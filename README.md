# engineering_practices

Engineering standards for Business Apps Engineering, mirrored from Confluence as
markdown so they can be read in-repo, diffed over time, and loaded by tooling.

## Start Here

- **[Engineering Standards 2026](standards/README.md)** — the hub: the 60-second
  summary, what's in flux, and how these pages relate to older ones.
- **[Technical Practices](standards/practices/README.md)** — the binding rules,
  one self-contained page per topic.

## Which Page Do I Need?

| Working on | Read |

| Class, method, variable names | [Naming Rules (Code)](standards/practices/naming.md) |

| Releases, rollout | [Deployment Strategy](standards/practices/deployment-strategy.md) |

## Source of Truth

Confluence is authoritative. Each file records the Confluence URL, page ID, and
last-modified date it was mirrored from. When the two disagree, Confluence wins —
and this repo needs re-syncing.
